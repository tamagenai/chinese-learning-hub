新しいアプリを追加する方法

プロジェクト内の apps-data.js ファイルを開き、配列の末尾に新しいアプリ情報を追加するだけで自動的に画面に反映されます。 

{
  id: "new-app-id",
  title: "アプリの名前",
  subtitle: "中国語のサブタイトル",
  category: "grammar", // grammar / speaking / tools / comprehensive / teacher
  categoryName: "文法・クイズ",
  level: "beginner",   // all / beginner / intermediate / advanced
  levelName: "初級",
  hskLevel: "HSK2級",
  icon: "fa-book-open",
  iconColor: "text-sky-600 bg-sky-50",
  badgeColor: "bg-sky-100 text-sky-800 border-sky-200",
  url: "https://your-app-url.com",
  description: "アプリの詳しい説明や特徴を書きます。",
  teacherNote: "先生からのおすすめポイントや使い方のコツ。",
  isFeatured: true,
  tags: ["タグ1", "タグ2", "初級"],
  estimatedTime: "5分"
}
学生への案内方法
  • 各カードの「共有」ボタンをクリックすると、URLがクリップボードにコピーされます。
  • このポータルサイト自体をGitHub Pagesなどで公開すれば、ポータルのURLを1つ教えるだけで全アプリを学生に案内できます。
